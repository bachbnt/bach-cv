What I've built at FPT

Engineering workflows the 5-person team uses every day, from the first bug report to the merged MR.

Bug-fixing pipeline

Traces root cause, then opens a fix MR, a vendor Q&A or paired design and code MRs. Evidence thresholds and a stale-ticket guard make it safe to run unattended.

Teams bot

Trace, fix, Q&A, resolve, ship and performance RCA from chat. Permissions are enforced per command; merge and resolve need two-step confirmation.

MR review and design-sync agents

The reviewer checks each MR against source, specs and project rules and marks problems as Draft. The sync agent applies merged design diffs across repos as per-repo MRs.

detekt-fix workflow

Proves each change is behavior-neutral by token-level diff. Lint cleared across 35 repo MRs with no suppressions, held in place by a pre-push gate.

Yokoten rollouts

An inventory script, a one-function pilot, then one MR per repo across every module for back-navigation, navigation-enum and resource-clearing fixes.

Build Portal

Python and Playwright. Replaced 30 batch scripts with one registry-driven script for one-click multi-module Android builds.
